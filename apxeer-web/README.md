# Apxeer web

The Preact, TypeScript, and Vite app provides lap browsing, session results,
and telemetry comparison. Follow the [local setup](../README.md#local-development)
to configure the API URL and Clerk publishable key and start the dev server.

Run `npm run build` to type-check and build into `dist/`. See the
[deployment guide](../docs/deployment.md) for publishing to Cloudflare Workers.
